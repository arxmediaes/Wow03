PUBLICAR EN GITHUB PAGES
1. Crea un repositorio nuevo en GitHub.
2. Descomprime este ZIP y sube index.html, la carpeta assets y .nojekyll a la raíz del repositorio. Sube los archivos, no el ZIP.
3. En Settings > Pages, selecciona «Deploy from a branch», rama «main» y carpeta «/(root)». Guarda los cambios.
4. GitHub Pages mostrará el enlace cuando termine la publicación.

No hace falta instalar dependencias ni ejecutar compilaciones.
El formulario de confirmación es una simulación: no envía ni guarda respuestas.
Las tipografías web y el mapa necesitan conexión a Internet.

Guía oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
